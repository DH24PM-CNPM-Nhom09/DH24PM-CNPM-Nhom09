# DevOps

Cấu hình Docker chuẩn của dự án nằm ở `frontend/docker-compose.yml` (chạy trong thư mục `frontend/`):
MariaDB + backend (build từ `backend/`) + frontend (`frontend/web`).
Hướng dẫn chi tiết: `frontend/TRIEN_KHAI_DOCKER.md`.

Thư mục này dành cho tài liệu và cấu hình DevOps khác (CI/CD, Render, giám sát, sao lưu).
